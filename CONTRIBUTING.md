# Contributing

Contribute only code you wrote yourself, or code you may relicense under MIT.

Record every external source you consulted in docs/provenance.md. Sign each
commit with a real Developer Certificate of Origin line. Never write another
person's sign-off.

Run the workspace test commands from README.md. State which physical-device
checks you actually performed. Keep unsupported and unverified behavior visible
in docs/support-matrix.md.
