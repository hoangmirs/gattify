# Contributing

Contributions must be original or legally reusable under MIT.

Every contribution must update docs/provenance.md for external material used and
include a real Developer Certificate of Origin sign-off in the commit. Never
fabricate another person's sign-off.

Run the workspace test commands from README.md and state which physical-device
checks were actually performed. Unsupported and unverified behavior must remain
visible in docs/support-matrix.md.
